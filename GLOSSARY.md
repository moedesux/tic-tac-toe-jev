# Voice tic-tac-toe

Terms used to discuss command interpretation and its debugging view.

## Language

**Jev exchange**:
One request sent to Jev to interpret a player's command, together with the response or failure for that request.
_Avoid_: Voice exchange, game response

**Jev debug panel**:
The collapsible view beside the game used to inspect Jev exchanges.
_Avoid_: Side window, console
